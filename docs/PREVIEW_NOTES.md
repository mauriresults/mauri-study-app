Mauri student 0.2.0 — Android preview

Green-and-gold study home, categorized library, Arabic/French search and filters, downloaded/favorite documents, persistent language/theme settings and storage controls. Android and iOS display names are Mauri student. Existing offline catalog and download records are retained during the SQLite upgrade.

This is a debug-signed preview, not a store release. CI runs Flutter analysis/tests, builds the APK, checks its Android application label and verifies its signature before publishing these assets. No physical-phone, iPhone or App Store verification is claimed. The universal debug APK includes multiple Android architectures and is larger than an optimized production build. No educational PDFs are bundled.

Download the APK and its SHA-256 file. Install only on a test Android device after allowing installation from your selected browser/file manager. Production signing, complete device/offline/performance tests, the remaining product features and the full Drive ingestion pipeline are still required.
